title: Diagnose a failure
description: Start from a stable diagnostic, prove the cause, and apply the bounded remediation.
---

## `V09_MIGRATION_EXECUTION_UNQUALIFIED`

The migration planner has the exact v0.7.1 release baseline, but the active-state handoff fixture has not
yet qualified mutation. Run the read-only proposal and the exact migration-execution gate; do not infer
write authority from source compatibility alone.

## `JOURNEY_PROVIDER_INCOMPATIBLE`

The selected adapter cannot provide a declared journey requirement. Choose a maintained profile/adapter or
remove the assertion only if it is genuinely outside the product contract. The result remains `blocked`.

## A plan fails before mutation

Read the diagnostic's node, capability, required guarantee, and configuration provenance. Correct the
ambiguous or missing binding, rerun `applik8s explain`, and review the new plan digest before applying.
