## One application, explicit guarantees

Write application semantics in ordinary typed code. Applik8s discovers the graph, resolves concrete
implementations, explains lifecycle and authority, and generates the runtime boundaries needed by the
selected profile.

<CardGrid>
  <Card title="Write application semantics" icon="pencil">
    Models, callable operations, events, jobs, workflows, and agents remain the application vocabulary.
  </Card>
  <Card title="Compose dependencies in code" icon="puzzle">
    Provider-neutral capabilities resolve to concrete implementations with explicit guarantees.
  </Card>
  <Card title="Explain before deploying" icon="magnifier">

  </Card>
