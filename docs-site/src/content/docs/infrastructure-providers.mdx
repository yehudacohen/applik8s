---
title: The infrastructure and provider boundary
description: Application semantics select capabilities; maintained implementations own physical resource details.
---

TypeKro authors Kubernetes resources and Alchemy deploys them. Native Alchemy resources own non-Kubernetes
managed infrastructure. External bindings contribute no infrastructure and declare the lifecycle operated
outside Applik8s. Application tutorials use capability constructors; provider authors document readiness,
upgrade, deletion, retained data, authority, and evidence explicitly.
