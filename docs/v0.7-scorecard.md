# Applik8s v0.7 scorecard

This scorecard is the release authority for the v0.7 Agentic Platform charter. It is intentionally
stricter than a package inventory: a capability is complete only when its public contract, maintained
implementation, generated-consumer path, and required live evidence all exist.

The machine-readable authority is
[`v0.7-scorecard.json`](./v0.7-scorecard.json). Run:

```sh
bun run check:v07:scorecard
bun run check:v07:scorecard:release
bun run check:v07:local
bun run check:v07:prerelease:orbstack
```

The first command validates the scorecard, checked-in contract evidence, generator budget, and pinned
compatibility boundaries. The release command additionally rejects every partial, pending, or blocked
item and requires schema-v3 receipts tied to the exact commit, complete working-tree digest, current
cluster UID, and classified per-assertion observations. A green contract scorecard is therefore not a
release claim.

`check:v07:local` is the complete source, package, contract, browser-security,
profile, performance-history, TypeKro, Stimp, maintained-application build, and
Rust host gate. `check:v07:prerelease:orbstack` runs that exact local gate, both
exact compiler-emitted PostgreSQL workers (event and authenticated typed HTTP),
the durable-signal PostgreSQL recovery suite, the graph lifecycle, the complete
maintained live application cohort, and the Starter, Dedicated, and External
Identity Start profiles before asking the release scorecard for authorization.
It cannot turn a partial scorecard item green by merely running unrelated
tests or by relying on receipts from an earlier source tree.

## Release policy

`v0.7.0` must not be tagged while any machine-readable scorecard item is `partial`, `pending`, or
`blocked`. External prerequisites remain visible as blocked items; they are not converted into passing
claims by fixture metadata. Multi-cluster qualification is the only explicitly deferred item and does
not block v0.7 because the charter excludes work requiring a second Kubernetes authority.
