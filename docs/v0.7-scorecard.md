# Applik8s v0.7 scorecard

This scorecard is the release authority for the v0.7 Agentic Platform charter. It is intentionally
stricter than a package inventory: a capability is complete only when its public contract, maintained
implementation, generated-consumer path, and required live evidence all exist.

The machine-readable authority is
[`v0.7-scorecard.json`](./v0.7-scorecard.json). Run:

```sh
bun run check:v07:scorecard
bun run check:v07:scorecard:release
```

The first command validates the scorecard, checked-in contract evidence, generator budget, and pinned
compatibility boundaries. The release command additionally rejects every pending or blocked item and
requires live receipts. A green contract scorecard is therefore not a release claim.

## Release policy

`v0.7.0` must not be tagged while any machine-readable scorecard item is `partial`, `pending`, or
`blocked`. External prerequisites remain visible as blocked items; they are not converted into passing
claims by fixture metadata. Multi-cluster qualification is the only explicitly deferred item and does
not block v0.7 because the charter excludes work requiring a second Kubernetes authority.
