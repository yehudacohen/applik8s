# v0.6 Foundation Boundaries

The v0.5 codebase prepares for streams, projections, and reactive clients without declaring those v0.6 capabilities implemented.

- Application graph serialization and compatibility validation are independent passes.
- TypeKro emission constructs a deterministic lowering plan before writing artifacts.
- Provider packages can run a framework-supplied registration conformance harness before provider-specific live semantics.
- Core contracts cannot depend on application authoring, compiler, runtime, Node, or TypeKro packages.
- Operator closure entrypoints remain WASM-safe.
- Browser client, React, and TanStack Start packages are pre-declared as browser-only dependency zones; Kubernetes, TypeKro, compiler, runtime, SDK, and Node imports fail the module-boundary gate.

The v0.6 contract phase still owns snapshot/delta/reset semantics, atomic snapshot/resume capability classification, cursor authorization, projection checkpoint modes, and the ClickHouse provider contract. This foundation deliberately does not freeze those semantics early.
