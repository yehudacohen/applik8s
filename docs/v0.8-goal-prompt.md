hoisting, and provider/application code must not import internal runtime

Follow the plan's semantic authority map as a correctness boundary. Provider
lowerings may cache, project, or transport canonical state, but must not create a
competing source of truth. In particular, telemetry is evidence rather than
correctness state; delivery metadata is not schedule admission; provider process
identity is not actor identity; target plans are derived from the semantic graph;
and query catalogs/caches are rebuildable from committed lakehouse publication
records. Fail closed when a provider cannot preserve the named ownership, retry,
recovery, or lifecycle semantics even if its happy-path values appear equivalent.
