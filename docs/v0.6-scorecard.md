# v0.6 scorecard

The executable v0.6 gate is `bun run check:v06:local`. It requires type/lint/module/package gates,
character coverage, Rust formatting and Clippy, host and bridge contracts, real
ComponentizeJS/WIT/Wasmtime invocation, plus focused native compatibility, common model context,
PostgreSQL transaction/migration, gateway/client, stream replay, ClickHouse projection, React/TanStack
integration, and graph validation tests.

Release evidence is split honestly:

- local and packed-consumer gates prove API/type/package/runtime boundaries without workspace aliases;
- PostgreSQL integration proves RLS, locking, rollback, duplicate recovery, and observable change order;
- the explicit OrbStack prerelease lane proves TypeKro lifecycle, migration Job, gateway/processor
  readiness, provider restart, and cleanup through the owning factory;
- performance history records snapshot/update, stream/projection, event application, graph construction,
  bundle size, memory, and concurrency envelopes.

The OrbStack receipt also records any bounded KRO 0.9 cleanup recovery. Application deletion is always
initiated and awaited through the TypeKro factory. After that succeeds, the harness may remove only a
completed, ownerless generated migration Pod and may clear only a terminating, empty generated CRD whose
RGD is already absent. These facts are explicit receipt assertions; they are not represented as native
KRO garbage-collection success. See [v0.6 Foundation Boundaries](./v0.6-foundation.md#kro-09-lifecycle-boundary).

The scorecard does not award evidence for a graph-only declaration or infer exactly-once behavior across
providers. A missing live environment is reported as missing release evidence, not converted into a pass.

Run `bun run check:v06:prerelease:orbstack` for release-candidate evidence. The lane refreshes real
PostgreSQL and ClickHouse receipts, deploys a generated TypeKro application on OrbStack, proves tenant
isolation, query invalidation, public-stream replay, durable ClickHouse projection, restart/resume, and
factory-owned deletion, then runs `scripts/check-v06-scorecard.ts --require-live`. Receipts live under
the ignored `.applik8s-tmp/evidence/v0.6/` directory, expire after 24 hours, and are evidence only for
the current machine and cluster—not tracked substitutes for CI results.
